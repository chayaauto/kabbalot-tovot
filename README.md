# קבלות טובות לישועה — הוראות הקמה

## 1. יצירת הפרויקט ב-Supabase
1. נכנסים ל-supabase.com ויוצרים פרויקט חדש (התוכנית החינמית מספיקה).
2. בתפריט: **SQL Editor → New query**, מדביקים את כל התוכן של `supabase-setup.sql` ולוחצים **Run**.

## 2. חיבור האתר
1. ב-Supabase: **Project Settings → API**. מעתיקים את **Project URL** ואת המפתח **anon public**.
2. פותחים את `index.html` ומדביקים אותם בשתי השורות בראש הסקריפט:
   ```js
   const SUPABASE_URL = 'https://xxxx.supabase.co';
   const SUPABASE_ANON_KEY = 'eyJ...';
   ```
   (המפתח הזה ציבורי ומותר שיופיע באתר. ההרשאות נשמרות במסד הנתונים.)

## 3. העלאת האתר
אפשר להעלות את `index.html` לכל אחסון של אתר סטטי, למשל Netlify (גוררים את התיקייה לאתר netlify.com/drop), GitHub Pages או Vercel.
אחרי ההעלאה: ב-Supabase **Authentication → URL Configuration**, להזין את כתובת האתר ב-**Site URL**, כדי שקישור האישור במייל יחזיר לאתר.

## 4. הפיכה למנהלת
נרשמים לאתר כרגיל, מאשרים את המייל, ואז מריצים ב-SQL Editor (עם המייל שלך):
```sql
update public.profiles set is_admin = true
 where id = (select id from auth.users where email = 'your@email.com');
```
אחרי רענון האתר יופיע "אזור מנהלת". אפשר להוסיף מנהלות נוספות באותה דרך.

## איך זה עובד
- **סימון שבועי:** כל משתתפת מסמנת "השתתפתי השבוע" (שבוע = ראשון עד שבת). ביום ראשון אפשר לסמן גם את השבוע שעבר, למי ששכחה במוצאי שבת.
- **כרטיסים:** כל שבוע מסומן = כרטיס אחד. כרטיסים נצברים מהגרלה להגרלה עד שהם נכנסים להגרלה.
- **ההגרלה:** נקבעת ליום שני, בכל תדירות שתבחרי. נספרים השבועות שהסתיימו לפני שבוע ההגרלה. ההגרלה בוחרת כרטיס אקראי מכל הכרטיסים, כך שמי שצברה יותר שבועות סיכוייה גבוהים יותר. אחרי ההגרלה הכרטיסים שנספרו מתאפסים.
- **מנהלת:** קובעת תאריך ופרס, רואה את כל המשתתפות ואת מספר הכרטיסים של כל אחת, ועורכת את ההגרלה בלחיצה (ההגרלה עצמה מתבצעת בשרת, כך שאי אפשר להשפיע עליה מהדפדפן).

## הערות
- כברירת מחדל Supabase דורש אישור מייל בהרשמה. אפשר לבטל זאת ב-**Authentication → Providers → Email → Confirm email**.
- שעון השבוע מחושב לפי שעון ישראל.
